# M3.5 visual identity

The KeyFlow mark uses three staggered keycaps and a spacebar. The launcher, splash, setup header and Windows icon share the same source artwork. Android also uses the mark as a monochrome notification and themed launcher glyph.

The shared palette uses slate blue and lavender with muted cyan highlights. Android setup and keyboard follow system light and dark modes. The keyboard uses translucent fills and subtle outlines for the glass effect. The current Windows tray uses the same icon, and its network dialog uses the light palette and defers to Windows colors in high-contrast mode.

Regenerate the assets from the repository root with Windows PowerShell.

```powershell
.\branding\Export-KeyFlowIcons.ps1
```
